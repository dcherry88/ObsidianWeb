# Getting Started

1. Use the **Web / Obsidian** toggle at the top left to switch views.
2. Press `/` or `Ctrl+K` to search names *and* text (try "roadmap").
3. Click **Show raw** to see this page's markdown source.
4. In Obsidian mode, open several notes as tabs and use **Split** to compare two.
